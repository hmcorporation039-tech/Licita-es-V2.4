### 4.2 Defeitos estruturais

- `html { font-size: 17.5px }` é zoom global disfarçado: infla todo espaçamento em ~9%.
- `layout.tsx` envolve tudo em `<main max-w-7xl>`; as páginas públicas colocam o `PublicShell` (com header, `<main>` e footer próprios) dentro dele → `<main>` aninhado e header preso a 7xl.
- `Nav` tem 8+ links numa linha sem breakpoint: quebra no celular.
- Abas do detalhe da licitação sem `role="tab"` e fora da URL (recarregar perde a aba).
- `dashboard` sem `.catch`: API fora = "Carregando..." eterno.
- Sem `loading.tsx`, `error.tsx`, `not-found.tsx`.

### 4.3 Direção visual proposta

Referência: ferramenta profissional densa (Linear, Stripe Dashboard, sistemas de mesa de operação), não landing page de SaaS.

| Decisão | Proposta | Evita |
|---|---|---|
| Tipografia | IBM Plex Sans + IBM Plex Mono (nº de processo, CNPJ, valores) com `tabular-nums` | Geist/Inter genéricos |
| Fundo | Papel quente `#F7F6F3`, superfície branca, linhas `#E4E2DC` | Cinza-azulado slate de fábrica |
| Acento | Uma cor só, usada com parcimônia: verde-petróleo `#0F5C4D` ou azul-tinta `#1F3A5F` | Indigo/roxo (a cor mais associada a "feito por IA") |
| Status | Paleta própria e única para ok/atenção/risco/neutro, reservada a status | 7 mapas divergentes |
| Forma | Raio 2–4 px, borda de 1 px, sem sombra, sem gradiente | Cards super-arredondados, glassmorphism, sombra difusa |
| Ícones | `lucide-react`, traço fino, inline com o texto | Ícone dentro de círculo colorido, emoji |
| Navegação | Sidebar fixa no desktop, drawer no mobile | 9 links numa linha |
| Dados | Tabelas densas com cabeçalho fixo; cards só no mobile | Tudo em card |
